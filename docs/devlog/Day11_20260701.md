**K-IFRS**
- pymupdf4llm이 본문을 제대로 파싱하지 못하는 문제가 발생하여 다시 fitz로 복원함. 표 추출이 다소 아쉽더라도 본문 파싱이 더 우선이라고 판단. 
- 도입, 적용사례, 결론도출근거는 제외하고 용어의 정의는 파싱될 수 있게끔 수정. 
- 테스트 결과 짧은 문단이 잡히는 경우가 많아 더 풍부한 답변을 위해 top_k를 8로 상향. 
- K-IFRS의 경우 인용을 따로 추출하여 모으는 대신 인용한 부분 직후에 근거를 표시하게끔 수정. 

**DART**
- DART 정정공시 XTML 파싱이 누락되는 부분이 발견되어 파서를 lxml_xml에서 html.parser로 변경함. 
- 또한 정정공시 검색 시 정기공시를 대상으로 제한되어 있던 것을 수정. 
- 정정 테이블이 여전히 잘 잡히지 않아 테이블 파싱 시 태그 대소문자를 무시하도록 수정하고 THEAD/TBODY 래퍼 없이 tr이 있는 경우를 찾을 수 있게 변경. 
- 삼성전자와 같은 대기업의 경우 API 100 제한으로 인해 정정공시를 전부 불러오지 못하는 문제가 발생하여 반복문으로 여러번 요청하게끔 수정.
