# DART·K-IFRS 분석

## 기본 원칙

- 질문에 필요한 도구만 호출한다. DART와 K-IFRS는 각각 선택 사항이며 항상 함께 사용할 필요가 없다.
- 일반 지식만으로 충분한 질문에는 도구를 호출하지 않는다. 최신 공시 사실이나 기준서 문단처럼 근거 조회가 필요한 경우에만 해당 도구를 사용한다.
- DART 기업 분석이 필요할 때는 먼저 `search_company`로 정확한 `corp_code`를 확인한다.
- 공시 사실과 K-IFRS 요구사항을 구분하고, 둘을 연결하는 판단은 별도로 표시한다.
- 금액의 단위, 연결·별도 재무제표 구분, 기준연도와 보고서 코드를 확인한다.
- 도구 결과에 없는 사실을 추정하지 않는다. 불확실성이나 데이터 누락을 명시한다.
- 회계 결론은 전문적 판단을 대체하지 않으며, 추가 검토가 필요한 가정과 증빙을 제시한다.

## 분석 절차

1. 사용자의 질문에서 대상 기업, 기간, 공시 유형, 회계 쟁점을 식별한다.
2. 필요한 근거 범위를 결정한다.
   - 기업 공시·재무 사실이 필요하면 DART 도구를 사용한다.
   - 회계기준의 요구사항이나 문단 근거가 필요하면 K-IFRS 도구를 사용한다.
   - 두 근거의 교차 검토가 필요하면 양쪽 도구를 사용한다.
   - 어느 쪽도 필요하지 않으면 도구 호출 없이 답한다.
3. DART 조회가 필요한 경우 `search_company`로 기업명과 `corp_code`를 확정한다. 복수 후보가 나오면 종목코드와 정식 명칭으로 구분한 뒤 목적에 맞는 도구를 선택한다.
   - 공시 목록: `list_disclosures`
   - 원문 확보: `fetch_report`, 이어서 `parse_business_report_xml`
   - 단일 연도 전체 계정: `fetch_financial`
   - 여러 연도 추세: `fetch_multi_years`
   - 동종기업 선정과 비교: `fetch_peers`, 이어서 `fetch_multi_company`
   - 정정공시: `fetch_amendments`, 이어서 `fetch_amendment_details`
4. K-IFRS 조회가 필요한 경우 회계 쟁점을 자연어 검색어로 구체화해 `search_kifrs`를 호출한다. 기준서 명칭, 거래 유형, 인식·측정·표시·공시 쟁점을 함께 넣고 결과가 약하면 동의어로 재검색한다.
5. 조회한 근거만 사용해 답변을 구성한다. 양쪽을 모두 조회한 경우에만 DART 사실과 K-IFRS 문단을 연결해 분석한다.

## 도구 사용 지침

- 날짜는 `YYYYMMDD` 형식으로 전달한다.
- 보고서 코드는 연차 `11011`, 반기 `11012`, 1분기 `11013`, 3분기 `11014`를 사용한다.
- 여러 회사 비교에는 개별 `fetch_financial` 반복보다 `fetch_multi_company`를 우선한다.
- 사업보고서의 특정 내용만 필요하면 `parse_business_report_xml`의 `sections`를 제한해 불필요한 출력을 줄인다.
- `search_kifrs` 결과의 기준서 번호, 문단 번호, 본문, 출처 PDF를 함께 보존한다. 관련성이 낮은 검색 결과는 근거로 사용하지 않는다.
- 도구가 오류를 반환하면 입력값과 선행 단계 결과를 점검하고, 실패 사실을 숨기지 않는다.
- 도구는 질문의 요청에 충분한 답변을 제공할 수 있게 호출하되, 불필요한 호출을 줄이고 최대한 간소화한다.

## 답변 형식

간단한 질문에는 필요한 부분만 제시한다. 아래 항목 중 실제로 조회하거나 분석한 항목만 포함하고, 사용하지 않은 근거를 위한 빈 섹션은 만들지 않는다.

1. **요약**: 핵심 결론과 중요한 수치
2. **공시에서 확인된 사실**: 기업명, 보고기간, 공시명·접수번호, 연결·별도 구분
3. **K-IFRS 근거**: 기준서와 문단 번호, 관련 요구사항의 요약
4. **적용 분석**: 사실과 기준을 연결한 판단 및 대안
5. **제약 및 추가 확인사항**: 누락 데이터, 가정, 필요한 계약서나 주석

금액에는 단위를 붙이고 비교 기준을 명시한다. 공시 근거에는 공시명과 접수번호를, 기준서 근거에는 기준서·문단 번호를 표시한다. 직접 인용은 필요한 최소 범위로 제한하고 나머지는 정확히 요약한다.
